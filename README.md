# Polynomial Regression Visualizer

An interactive single-page web application for learning how Polynomial Regression works. It visualizes data points, the fitted polynomial curve, model parameters, and loss during gradient descent training.

## Features

- Generate random datasets, click to add/erase points, or spray points in and out with an adjustable brush.
- Left and right panels scroll independently.
- Adjust the polynomial degree and training parameters.
- Train the model one step at a time or until convergence.
- View the fitted curve, model state, feature matrix, and loss graph.
- Run directly in a browser with no build step.

## Getting Started

Open [`index.html`](./index.html) in a modern web browser.

The project is a static website, so no package installation or development server is required.

## GitHub Pages

This repository includes an automatic deployment workflow in [`.github/workflows/deploy-pages.yml`](./.github/workflows/deploy-pages.yml).

To enable it:

1. Push the repository to GitHub.
2. Open **Settings > Pages**.
3. Set the Pages source to **GitHub Actions**.
4. Push or merge changes into `main`.

GitHub Pages will publish the site automatically after the workflow completes.
