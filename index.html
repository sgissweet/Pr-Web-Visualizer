Polynomial Regression — Step by Step

Polynomial Regression fits a curve y ≈ w₀ + w₁x + w₂x² + ... + wdxd to data by treating powers of x as extra input features, then using Gradient Descent to nudge the weights w a little bit at a time so the average squared error between predictions and real points keeps shrinking. Add or randomize points on the left, then press Step to watch one update happen, or Play to watch it converge.

Update Rule
Cost:  J(w) = (1 / 2n) · Σᵢ (ŷᵢ − yᵢ)²
Gradient:  ∂J/∂wj = (1 / n) · Σᵢ (ŷᵢ − yᵢ) · xij
Update:  wj ← wj − α · ∂J/∂wj
